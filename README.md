# Postkort – Sejersminde B&B

Print-klar postkortskabelon (A6, dobbeltsidet) til `_bb.html`:
- **postkort-bb.html** – færdigt kort til Sejersminde B&B (billeder, tekst, QR indlejret)
- **postkort-skabelon.html** – generisk skabelon med pladsholdere

Print: åbn filen i browseren → Ctrl+P → A6, skala 100 %, margener 0, baggrundsgrafik til.
